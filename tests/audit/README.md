# Scene3D proof audits

These files preserve exhaustive rendering, alias-history, and mutation proofs that are too costly for routine unit/visual lanes. CI runs them in the `audit` job (3 groups) when `scripts/ci-plan.js` finds a change that matches `scripts/audit-paths.js`, on every main push that is not deduplicated, and nightly. The audit loader (`tests/helpers/scene3d-audit-runtime.js`) throws if an audit evaluates a script outside that path filter; routine tests remain in `tests/unit/` and `tests/visual/` so selecting them does not execute audit `beforeAll` hooks. The former `tests/audit/unit/` copies were removed so every proof has one collected copy.

| Routine guard | Preserved proof | Distinct failure mechanism |
| --- | --- | --- |
| `unit/scene3d-tone-law-collapse.test.js` | `audit/scene3d-tone-law-collapse-a-combo.test.js`, `-b-single` (same prefix, `.test.js`), `audit/scene3d-tone-law-caveat-visibility.test.js` | All fold-cluster render equivalence, multi-primitive/density sweeps, caveat history, resolver mutation evidence, and synthetic-alias migration behavior. |
| `unit/scene3d-tone-law-dispatch.test.js` | `audit/scene3d-tone-law-dispatch.test.js`, `-dispatch-wave`, `-dispatch-mono` | Full law roster, every law's dispatch distinction and crosshatch mono laws. Audit renders each law once and reuses scalar summaries. |
| `unit/scene3d-mktick-spacing-tone.test.js` | `audit/scene3d-mktick-spacing-tone.test.js`, `audit/scene3d-mktick-spacing-tone-bce{,-chain,-crumbs,-rim}.test.js` | Full density/primitive/rig matrix and named mutants for spacing, contacts, clipping, coverage, wedges, continuation, rims, and apex behavior. Mutant runtimes are constructed and cleaned up serially; tests compute their own immutable result summaries instead of reading sibling-test state, and raster/geometry evidence is kept only for direct consumers. |
| Mechanism tests across `unit/scene3d-*` | `audit/scene3d-golden-corpus.test.js` | Broad drift canary, not a mechanism proof: 35 small canonical scenes (primitives x fill styles, wireframe hidden edges, slice, x-ray, HLR, cast and received shadows, boolean, perspective, imported mesh), one hash per output path plus counts/ink/bbox in `tests/baselines/golden-values/scene3d-golden-corpus.json`. |
| `visual/scene3d-tone-baseline.test.js` | Same file; no proof moved | Each scenario still runs three fresh times for deterministic summaries and mutation checks run fresh source; immutable summaries are reused across assertions within that fixture. |

Audit tests use the same `tests/helpers/` depth convention as unit tests. Run them locally with `npm run test:audit:proofs`, or one file with `npm run test:vitest -- run tests/audit/<file>`.
