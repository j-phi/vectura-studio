# Code-Level Touch Input Audit — iPad 11" / iPhone Pro (iOS Safari)

- **Type:** Static code audit. READ-ONLY. No device runs were made.
- **Scope:** `src/render/renderer.js`, `src/ui/**`, `src/ui/skin/components.css`, `index.html`.
- **Date:** 2026-10-02. Branch `main` (HEAD `e609338c`).
- **Status:** NOT visually verified. Items tagged *(verify on device)* depend on WebKit behaviour that varies by iOS version.

## 1. Summary

| Severity | Count |
|---|---|
| Blocker | 5 |
| Major | 16 |
| Minor | 19 |
| **Total** | **40** |

### Top 5

1. **CODE-001** — On-canvas Type tool reads only `window` `keydown`. No focused editable element exists, so the iOS soft keyboard never opens.
2. **CODE-002** — "Convert to Scene", "Create boolean group", "Drop to Ground", "Select All Faces of Object" exist only in `contextmenu` menus. iOS Safari does not fire `contextmenu` on long-press.
3. **CODE-005** — Pinch-zoom is refused when the first finger already started a marquee, pen anchor, lasso, or scissor action. With the default Select tool, pinch on empty canvas usually fails. There are no on-screen zoom buttons.
4. **CODE-010** — Reorder grips and the angle dial run through the touch→mouse bridge, but they have `touch-action: manipulation` (from the coarse `button` rule) or no `touch-action`. A vertical drag scrolls the panel, iOS fires `pointercancel`, and the drag ends early.
5. **CODE-016** — `body`/app wrapper use `100vh` (no `dvh`/`svh`). On iPhone Safari, the bottom of the app (the modifier bar, pane bottoms, bottom pane) sits under the browser toolbar.

## 2. Layout classification (JS breakpoints)

Source: `src/ui/shell/workspace.js:71-84` (`applyAutoCollapse`). `phone-layout` < 540, `auto-collapsed` < 640, `mobile-layout` < 900 (`window.innerWidth`). The touch modifier bar shows when `isTouchCapable()` (`(pointer: coarse)` or `maxTouchPoints > 0`) OR when `mobile-layout` is set (`src/ui/ui-touch.js:50`, `workspace.js:65-69`).

## 4. Existing touch infrastructure worth reusing

- **`renderer.getModifierState(e)`** (`renderer.js:1849`) merges real keys with `SETTINGS.touchModifiers`. Extend its use to panels (CODE-004, CODE-006).
- **Touch modifier bar** (`index.html:624-629`, `src/ui/ui-touch.js:15-63`): Shift / Alt / Cmd / Ctrl / Pan latches. It covers Shift constrain, Alt duplicate/erase, Cmd multi-select on canvas, and Space-pan. It does not cover Esc / Enter / Backspace / Delete / arrow keys, wheel, or right-click.
- **Canvas pinch/pan state machine** (`renderer.js:1883-1975`, `touchPointers` Map, `startTouchGesture`/`updateTouchGesture`/`cancelActiveInteractionsForTouchGesture`) — pinch zoom + center-pan, already correct once started.
- **Canvas hold-to-lift** (`renderer.js:7209-7231`) and the 12 px pan conversion (`7356`).
- **Petal Designer** has its own pinch (`ui-petal-designer.js:3023-3150`) and reads `touchModifiers` (`2951`, `4012`, `4050`). It is the best template for the export preview and the Pattern Designer.
- **Layer list touch drag** (`layers-panel.js:260-431`): long-press, `elementFromPoint` targeting, group/mask/exit zones. Template for the mirror rows and the grips.
- **Touch→mouse bridge** (`ui-touch.js:65-118`) — works once `touch-action: none` is on the targets.
- **Toolbar long-press flyouts** (`toolbar.js:308-361`, `496-572`) — template for a long-press context menu.
- **Armed-pen tap** (`pens-panel.js:444-449`) — a touch alternative to the HTML5 pen→layer drag.
- **Shared slider** (`components/slider.js:72-77`): tap-editable `inputmode="decimal"` chip. Template for CODE-013.
- **CSS coarse blocks**: `components.css:3983`, `4025`, `7862`, `8758` (16 px inputs, 44 px tool buttons, `manipulation`), `9402` (callout/selection suppression), and the bottom-sheet modal at `4025`.
- **Manual double-tap detectors** (`renderer.js:2082`, `2735`, `7047`) — keep them, but scale the radius for touch.

## 5. Notes for device verification

Check these items on a real iPhone/iPad first, because WebKit behaviour decides their severity: CODE-012, CODE-013 (`dblclick` delivery), CODE-029 (HTML5 DnD), CODE-030, CODE-036, and CODE-037. Use the Playwright WebKit project with `hasTouch: true` for a first pass. Note that Playwright WebKit does not reproduce iOS `100vh`, the file picker, or download behaviour.
