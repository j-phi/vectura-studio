# TUX-017: Gesture arbiter, two fingers always pan and zoom

## CHANGELOG
- Pinch and two-finger pan now work with every tool, wherever the fingers land (Select, Direct Selection, Pen, Lasso, Scissor, Shape, Fill, Hand, Type and the 3D scene drags). A second finger that lands within 250 ms of the first, or before the first moved 10 px, cancels the first touch action completely: no selection change, no edit, no pen anchor, no history entry. A later second finger commits the first action as one undo step, then starts the pinch. After a pinch, the remaining finger does nothing until every finger lifts. New module `src/render/touch-gesture-arbiter.js` and config `UI_CONSTANTS.TOUCH_GESTURE` (`ARBITRATION_MS`, `ARBITRATION_SLOP_PX`). Fill pours, the plain-marquee clear and pen add/delete-anchor edits now run at finger lift on touch. Fixes IPH-007, JRN-003, CODE-005 and CODE-023.

## README / help / shortcuts
- Help (Touch page) and README touch section: "Pinch and two-finger pan work with any tool. Put two fingers on the canvas, wherever you like. A second finger that lands within 250 ms of the first, or before the first moved 10 px, cancels the first touch. A second finger that lands later keeps what the first finger did and then starts the pinch. After a pinch, lift all fingers before you start the next action."
- Shortcut list: none (touch gesture, not a key).

## Device checklist (docs/touch-audit/device-checklist.md, section 4.2 row 10)
- Row 10 text: "10 of 10 real pinches from empty canvas and 10 of 10 from a selected object start the zoom and change nothing else (selection, anchors, history). Two fingers that land together also zoom. Drag an object for 400 ms, then add a second finger: the object stays moved, undo reverts it in one step, and the pinch works."
