# TUX-042 fragment: text-entry controls compute >= 16px on coarse pointers

## CHANGELOG bullet
- **Touch: no iOS focus zoom.** Under `(pointer: coarse)` every `input` (text-like or untyped), `select` and `textarea` computes `font-size >= 16px` (`--input-font-touch`). The rule sits at the end of `components.css` and uses `!important`. This is the only way to beat the skin rules (0,2,0)-(0,3,0) and the inline `font-size:10px` on the Text panel selects (`ui-text-panel.js` lines 1509 and 1513) without editing lane T's file. `[contenteditable]` is not in the rule, so the 34px `.vtp-spec-text` specimen is unchanged. The Pens name input now declares `type="text"`. Fine pointers are unchanged.
