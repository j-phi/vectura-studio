# TUX-046 modal sheet

## CHANGELOG bullet
- Touch: Export, Help, info dialogs, the colour picker, Document Setup and the Save Preset sheet now follow one sheet contract (`.vt-sheet`). Header (with close) and footer stay pinned and only the body scrolls. On phones each sheet fills the screen inside the safe area. On tablets the card fits the viewport. The close button, Export nav tabs and footer buttons are at least 44 px under a coarse pointer. The modal overlay sits above the app header (z-index 900). Opening a modal on touch no longer focuses a text field, so the keyboard stays down. Choosing a command in the phone hamburger menu now closes the menu.
