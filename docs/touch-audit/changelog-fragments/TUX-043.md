# TUX-043 fragment: sliders are finger-sized; scrolling and tapping never change a value

## CHANGELOG bullet
- **Touch: sliders are 44px tall with a 28px thumb, and only a sideways drag changes a value.** On coarse pointers every `<input type="range">` gets a 44px box, a 4px track (pen 3px, draw-order 6px) and a 28px centred thumb (`--touch-slider-thumb`), with `touch-action: pan-y` (`pan-x` on the vertical Text-panel slider). One delegated controller, `Vectura.UI.RangeTouch` in `slider.js`, handles touch and pen pointers on all ranges: a vertical swipe scrolls the panel, a tap on the track does nothing, and a sideways drag from the thumb or the band moves the value relatively (1:1 with the finger), with one `change` on release. Dual ranges move the thumb nearest the touch. Mouse and trackpad keep the native track-jump and the double-click reset.

## Decisions / notes
- Q7: draw-order tap-to-play is kept. A tap plays from the current handle position; the handle no longer jumps to the tap point on touch. The controller never stops pointer events, so `shortcuts.js` needs no change.
- Pointer policy: `touch` and `pen` are controlled. `mouse` is never touched (native track-jump and `dblclick` reset stay, also on an iPad trackpad).
- Native browser `input`/`change` events (trusted) are restored and swallowed at window capture during a touch gesture and for 500 ms after it. Untrusted programmatic events pass, so undo and `setValue` are not blocked.
- Gap: exact entry on legacy `attachValueEditor`-span sliders (algo-config-panel) and `.pen-width-value` arrives with TUX-038.
- Pen rows (TUX-041 two-line layout) leave the pen slider only about 55px wide on iPhone portrait. The control works, but a wider slider needs a layout call in the pens panel.
- J1 slider-step cell: not flipped. It cannot strict-PASS on iPhone until TUX-010 lands.
- D4: this branch has no `tests/e2e/touch/target-baseline.json`, so no baseline was lowered. `targets-controls.spec.js` still excludes ranges; lane H can include them now (the input box is 44px).
