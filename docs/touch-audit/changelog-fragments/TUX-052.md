# TUX-052 Touch help page and touch status hints

## CHANGELOG bullet
- Help has a Touch tab and a Touch toggle. It opens on Touch when the app runs in the touch layout (body.touch-ui). The status hint line switches to touch words (Tap, Multi-select + Tap, Constrain + Drag) after touch or Apple Pencil input and returns to mouse words after a mouse click. Mouse hint text is unchanged.

## Notes for the integrator
- Touch page lists only accepted behaviour. It excludes canvas hold (034b), tap-outside close, canvas double-tap add layer, double-tap isolate/rename, layer auto-scroll, TUX-033 latches, toast position and the TUX-039 hold-for-name claim.
- Mouse segments with no proven touch path (for example Cmd+Click cycle in Fill) are omitted from the touch table.
- Desktop parity: `tools` table unchanged; a mouse Mac still defaults Help to Mac.
