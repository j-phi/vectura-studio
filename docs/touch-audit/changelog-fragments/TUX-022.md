# TUX-022 Paint bucket preview and scope by touch

## CHANGELOG bullet
- Paint bucket on touch and pen: press shows the region preview and a loupe above the finger, lift pours into the last previewed region. A cancel, a drag off the paper or a second finger pours nothing. Scope ▲/▼ chips (44 px, context bar, coarse pointers only) widen and narrow the previewed region. Mouse behaviour is unchanged.

## Interface notes
- TUX-045: switch the fill drag-pour and CMD adopt from `e.shiftKey` / `e.metaKey` to `getModifierState(e)`.
- Harness lane: `touchPhase(page, 'cancel', ...)` in Chromium must send `touchPoints: []`. TUX-018 already did this on this branch. The spec uses an in-page synthetic `pointercancel`, so it does not depend on the helper.
- Merge point: `playwright.config.js` desktop-chromium `testMatch` gained `|paint-bucket-mouse\.spec\.js$`.
- `src/render/touch-gesture-arbiter.js` INTERACTION_FLAGS gained `_fillPendingPour`.
- `.ctxbar` is hidden at max-width 640px by the generic phone rule. The new `.ctxbar--fill` class (set by `renderContext` for kind `fill`) overrides it, so the chips show on phones. TUX-030/031 and TUX-034 should keep this class.

## Deviations from the brief
- TUX-017 had already landed `_deferTouch(pour, 'window')` for the fill pour. TUX-022 removes that call for fill. Pinch (f) and cancel (d) already passed on this branch before the fix. The failing REDs were (a) loupe, (c), (e), (g), (i), (j).
- CODE-017 narrowed to fill feedback only (region highlight, loupe, hint). General hover chips, labels and the 3D hover hint during a hold belong to TUX-034/019. The orchestrator must update the section 6.1 row.
- The fill bar rides the bottom edge of the viewport so it does not cover the region. On iPhone landscape the loupe can cover the right chip while the finger is near the bottom of the short canvas.
- Req. 6 (hover chips) not done here, see above.
