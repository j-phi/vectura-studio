## Interface notes for the integrator
- `src/app/app.js`: `captureState` adds `layerLockedIds`; `applyState` restores it (same Set instance) before `renderLayers()`. Restore re-adds a snapshot lock id only for a layer the restore brings back (absent before applyState) or its child; locks set after the checkpoint survive an unrelated undo. Old snapshots without the field leave locks unchanged.
- `.vectura` file format: unchanged. `saveVecturaFile` strips `layerLockedIds` from the saved state (it is an undo-snapshot detail), so open, rollback and tutorial restore behave as on the base.
- `tests/e2e/touch/journey-status.json`: J12 iPhone landscape (touch + webkit) moved from `boot` to `j12.undo-gesture`.
- `src/ui/panels/pens-panel.js` (lane C, 041/042/043): only the body of `removePen` changed: `penToken`, `penName`, and a final `this.notifyUndoable?.(...)` call.
- `playwright.config.js`: `delete-undo-desktop.spec.js` added to the desktop-chromium testMatch.
- `tests/unit/touch-delete-undo-guard.test.js` pins `removeLayer(` text count under src/ui at 6 (was 8: three layer-context-menu sites now share `_deleteLayerWithUndo`).
- Toast host positioning moved from inline style to `#vectura-toast-host` in components.css (TUX-037 block). `--tux-safe-*`, `--tux-toast-gap` in tokens.css. `--tux-modbar-clear` is set by toast.js from the measured modifier bar.
- Fix round 2: the Undo toast alone is `position:fixed` bottom-center on coarse pointers (a plain toast stays top-right); inline `max-width:320px` moved to CSS; hover pause ignores compat mouse events after a touch pointerdown; the press flag clears on a document-level pointerup/cancel.
