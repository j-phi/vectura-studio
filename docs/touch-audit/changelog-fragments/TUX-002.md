# TUX-002 / TUX-003 / TUX-004 fragment (lane touch/shell, S3)

## CHANGELOG bullet
- Touch shell: the page no longer scrolls, rubber-bands or pulls to refresh (fixed body, `overscroll-behavior: none`, every inner scroller contains overscroll). Pinch on panels, toolbars and modals no longer zooms the page (`touch-action: pan-x pan-y` plus a `gesture*` guard in `ui-touch.js`). Heights use `--app-vh` (`100dvh`) instead of `100vh`; `h-screen` is removed from `<body>`.

## Accepted desktop delta
- `html { overscroll-behavior: none }` disables two-finger history swipe-back in Chrome and Edge on macOS.
- The gesture guard registers only on touch-capable devices, so desktop Safari trackpad page zoom is kept.
