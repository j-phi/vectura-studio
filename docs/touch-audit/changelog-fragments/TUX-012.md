# TUX-012: Two-row touch layer rows with grip and ⋯

## CHANGELOG
- Layers panel on coarse pointers (or `body.touch-ui`): rows use two lines. Row 1 is grip, name, ⋯. Row 2 is eye, lock, pen dot, type label (groups, modifiers and scenes put the caret first). Names show at least 96 px, hit areas are 44 px, and nothing leaves the pane. Secondary actions (mask, Expand, Duplicate, Delete, Ungroup, scene add) move into the ⋯ menu. Drag the grip to reorder at once. Desktop rows are unchanged. The old `min-width:600px` "2x Layer cards" CSS block is removed.
