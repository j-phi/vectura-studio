# TUX-034a: long-press and ⋯ context menus (layers)

## CHANGELOG
- Touch: press and hold a layer row for 0.5 s to open its menu. A ring shows the hold from 0.15 s, the row pops and the device gives a short tick when the menu opens. The menu opens beside the finger, never under it. Lifting the finger runs nothing. Moving 10 px before the menu opens cancels the hold. Mouse behaviour is unchanged (right-click opens the menu, drag still reorders).
- Touch: the old 350 ms hold-to-reorder on the row body is removed. Drag the grip at the left of a row to reorder (starts after 4 px).
- Touch: the ⋯ button on every row now has `aria-haspopup="menu"` and `aria-expanded`.
- Context bar ⋯ menu: new item "Selection menu…" (shown when a layer is selected). It opens the canvas right-click menu without a mouse.
- Context menus fit short screens. Rows are 44 px on touch, the menu scrolls inside, and a finger scroll in the canvas menu no longer closes it. A window-blur check no longer closes the canvas menu when only an element loses focus.
- New module `Vectura.UI.TouchHold` (`src/ui/touch/touch-hold.js`). New config `Vectura.TOUCH_HOLD` in `src/config/context-menu.js`.
