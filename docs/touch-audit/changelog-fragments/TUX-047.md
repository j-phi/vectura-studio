# TUX-047 pinch and two-finger pan on Export preview and Pattern Designer

## CHANGELOG bullet
- Touch: a two-finger pinch now zooms the Export preview and the Pattern Designer canvas about the finger centre. A two-finger drag pans. The page no longer zooms. One finger keeps the active tool. In the Pattern Designer a touch tool action now waits for finger-up, 250 ms, or 10 px of movement, so the first finger of a pinch never pours a fill, selects a path, adds an anchor or writes history. A pointercancel ends any drag with no new history. Mouse and pen are unchanged. New shared helper `Vectura.UI.PinchZoom` (`src/ui/components/pinch-zoom.js`).
