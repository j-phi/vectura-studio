# TUX-048 Toasts bottom-centre on touch

## CHANGELOG bullet
- Toasts on touch devices (body.touch-ui) now sit bottom-centre, inside the safe area, above the bottom modifier bar and above open modals. Plain status toasts no longer take taps. Desktop keeps the top-right placement.

## Notes for the integrator
- `toast.js`: all inline `style.cssText` removed; `positionHost` replaces TUX-037 `syncModbarClear` (`--toast-bottom` replaces `--tux-modbar-clear`). Class `is-actionable` (onClick or action) and `has-action`.
- Supersedes TUX-037 fix round 2: plain toasts now also dock bottom-centre on touch. `delete-undo.spec.js` updated (safe-area token is now `--safe-bottom`; plain toast asserted bottom-centre).
- The TUX-037 `@media (pointer: coarse)` toast placement rules were removed. `--tux-toast-gap` / `--tux-safe-*` stay (used by context-bar.js).
- Deviation: 800x700 desktop parity asserts top in {16, 52}: the pre-existing TUX-010 tablet-layout rule (width keyed) gives 52. Safe-area spec injects `--safe-*` tokens on both engines (no CDP override), per the TUX-005 precedent.
