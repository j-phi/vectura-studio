# TUX-027 fragment: mirror angle dial has fine touch control; row actions are finger-sized

## CHANGELOG bullet
- **Touch: the mirror angle dials turn in fine 0.5 degree steps, and the row actions are finger-sized.** With a finger, a sideways drag across any mirror dial (line angle, radial angle, arc rotation offset, wallpaper pattern angle, and the tile-angle range gauge) moves the value relative to where the drag began, at exactly 0.5 degrees per px. A tap on a dial changes nothing and adds no undo step. Compass dials wrap through 0..359; the tile-angle gauge clamps to its 45..135 range. Mouse and pen keep the absolute click, Shift-snap and double-click reset. The Angle row's own range slider follows the same 0.5 degree per px rule for finger and pen drags (a mostly vertical gesture over it changes nothing); mouse keeps the native absolute slider. The value chip stays the one-tap exact-entry path (decimal keypad). On touch-ui the mirror row's Disable, Lock and Delete buttons are 44x44 on their own right-aligned line, so the row name keeps its width.

The touch rule lives in one pure helper, `MirrorPanel.touchDialValue(start, dx, mode, min, max)` with `TOUCH_DIAL_DEG_PER_PX = 0.5`. Follow-up: let `angle-dial.js` adopt `touchDialValue` later.
