# TUX-030 Pen draft controls

**CHANGELOG bullet:** Touch: a Pen draft now shows Done, Remove Last Anchor and Cancel chips in the context bar (44 px targets on a coarse pointer, visible on iPhone portrait and when the Contextual Task Bar is off). Done is disabled under two anchors. A tool change commits a draft of two or more anchors instead of discarding it. Undo, redo and opening a file drop an open draft and never commit it. On narrow layouts the draft bar sits clear of the overlay panes and tight to the canvas bottom edge, so it leaves the central drawing band free.

**plans.md line:** TUX-030 done - pen draft chips (context-bar `pen-draft` kind), commit-on-tool-switch. Follow-ups: Space-pan keeps the draft (render lane), Undo removes last anchor during a draft (TUX-020), fill Done chip (TUX-022), phone ctxbar gap (journeys.md:67), double-tap radius >=24 px (TUX-024).

**README / Help text:** "While drawing with the Pen, tap Done to finish the path, Remove Last Anchor to step back, or Cancel to discard it. Switching to another tool finishes a path of two or more anchors."

**Shortcut list:** no new keys. Enter, Backspace and Escape keep their meaning.
