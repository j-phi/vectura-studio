# TUX-018a — pointercancel aborts, never commits (renderer part)

## CHANGELOG bullet
- A system interruption mid-edit (Control Center, notification, palm, OS takeover) now cancels the edit instead of committing it. The canvas restores the pre-gesture state, adds no history entry and leaves the redo stack alone. Foreign cancels from panel controls are ignored. A cancel of one pinch finger keeps the view.

## plans.md line
- TUX-018a done (renderer): `abortActiveInteraction` plus `onPointerCancel` in `renderer.js`. 018b open: pointercancel pairing for UI handlers and the `bindPointerDrag` helper.
