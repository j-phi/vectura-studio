# TUX-026 Petal Designer usable by finger

## CHANGELOG bullet
- Touch: the Petal Designer now works by finger. A finger grabs an anchor from 22 px away (the mouse keeps 10 px), and a handle under the finger wins over its anchor. On a touch device the tool, pop-out, pop-in, close and Import/Export buttons are at least 44x44 px. The pop-out window always fits the screen: it is clamped to the visible area and the safe area, it re-fits on resize, rotate and keyboard changes, and a header drag cannot push it off screen. On phones the pop-out opens as a full-screen sheet with a pinned header. Desktop: the pop-out no longer starts 30 px below the screen bottom at 1600x1000 (bug fix, see the D6 exception).

## D6 desktop exception (declared by the binding brief)
The desktop pop-out window clamp is a bug fix. At 1600x1000 the open pop-out used to end at y=1030 (30 px off screen). It now ends at 988 or above, and it starts below the app header. Every other desktop surface is unchanged. Mouse hit behaviour is proven unchanged by `tests/unit/petal-designer-hit-radius.test.js` (mouse, no options and pen keep the 10 px nearest-control rule). No visual baseline captures the open designer window, so none was updated.

## Setup shims and deferred items (honest list)

The inline designer then renders on every project, including iPhP, so the iPhP inline anchor-grab, delete and handle tests RUN. They do not use the `popOutInlinePetalDesigner()` shim.
- Window-open: the test taps the inline pop-out button by finger when it is hittable (all projects here). `ui.openPetalDesigner()` is the fallback shim only if the button is not reachable; the test annotates `shim` when it fires. It did not fire in any project.
- Deferred until TUX-010 lands: opening the left pane by finger on phones, then repeating the iPhP inline anchor grab through that route.
- Pinch (clause 2) was already satisfied: the inline canvas already ran the pinch state machine. The pinch test is a regression conversion (green before and after). Pinch zooms one side; the mouse wheel zooms both sides. Decide later if they should match.
