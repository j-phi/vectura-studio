## API
- `Vectura.LayoutClassifier.classify({width,height,coarsePointer})` pure.
- `.readInput()` reads innerWidth/innerHeight and `(pointer: coarse)`. No visualViewport.
- `.current()` last result. `.apply(doc)` toggles classes, sets `data-layout`, returns the layout.
- Event `vectura:layoutchange` on window, `detail {from, to, coarsePointer}`, only on a real change.
- Thresholds: `Vectura.TOUCH_LAYOUT` in `src/config/defaults.js`.
- `auto-collapsed` is unchanged (innerWidth < 640). TUX-008 owns it.
