# TUX-035: add-layer algorithm drill-down on tap

## CHANGELOG
- Touch: tapping "Algorithm Layer" in the Layers add menu no longer adds a stray default (Attractor) layer. It opens the algorithm list inside the menu. A "‹ Algorithm Layer" row returns to the first menu. Tapping an algorithm adds exactly one layer of that type.
- The drill-down rows are 44 px tall. The list scrolls inside the menu and fits the visible viewport and the pane (iPad, iPhone landscape, Chrome-bar variants).
- Mouse behaviour is unchanged: hover opens the fly-out, a click on the row adds the default layer. The fly-out now also closes when an item is picked or the menu closes (it was left orphaned before).
- The fly-out opens on mouse pointer events only (`pointerenter`), so touch taps never trigger a hover-driven DOM change.
