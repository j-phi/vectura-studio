## README / help / shortcuts
README: "Touch: the modifier bar has four tasks. Tap once to apply a task to the next gesture. Tap twice quickly to lock it. A badge on the canvas shows active tasks."

Help, Touch page:
- Multi-select: add to or remove from the selection (the Shift or Cmd click on a desktop).
- Constrain: lock a drag to an axis or keep a shape square (Shift on a desktop).
- Duplicate: drag a copy, draw from the center, or erase with the fill tool (Option on a desktop).
- Pan: drag one finger to move the canvas.
- One tap = one gesture. Two taps within 300 ms = locked until you tap again. A pinch or a cancelled gesture keeps a one-shot task.
- Not on touch (use the alternative): Cmd snap-off (use the View snap toggle), Cmd from-center (use Duplicate), Cmd square marquee, Cmd no-snap-close, Cmd pen-select override (use the Select or Direct tool).
- A mouse or trackpad never uses these tasks. A real keyboard Shift still works.

## Reader to task table (amend requirements section 3)
| Reader | Task |
|---|---|
| additive selection (`modifiers.additive`: shift, meta, ctrl, or Multi-select) | multiSelect |
| Direct tool anchor toggle and segment multi-select (`modifiers.rawShift || modifiers.multiSelect`; a Constrain latch does not toggle anchors) | multiSelect |
| shift constraints (axis lock, square, snap angle) | constrain |
| alt duplicate-drag, erase alternate, from-center, break handle | duplicate |
| pan | pan |
| meta snap-off, meta from-center, meta square marquee, meta no-snap-close, meta pen-select | dropped on touch |
Multi-select never sets shift or meta. No task sets meta or ctrl.
