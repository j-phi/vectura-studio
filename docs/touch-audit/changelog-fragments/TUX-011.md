# TUX-011 Backdrop dismissal and no slivers

## CHANGELOG bullet
- Touch: a closed panel on a phone leaves no 40 px sliver on the canvas edge. The canvas takes touches up to both screen edges. Closed panels are `inert`. The dimmed backdrop closes the drawer on `click` only, so no ghost click reaches the canvas. The backdrop sits above the tool rail. On phones the header stays above the backdrop, so Generator and Layers stay tappable. (TUX-011)
