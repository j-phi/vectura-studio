# TUX-044 (044a): panel-list reorder and angle dial on touch

CHANGELOG bullet:
- Touch: noise, effect, modifier, optimization, pen and mirror lists now reorder with a finger. All lists share one pointer-event helper (`Vectura.UI.PointerReorder`). A cancelled gesture aborts and changes nothing. The list scrolls itself when you hold a grip near the pane edge. The angle dial keeps its own finger drag and restores its start angle on cancel. Mirror rows get a drag grip. A downward drop now lands in the slot shown by the indicator (the old handlers landed one slot short).

plans.md line:
- TUX-044a done (panel lists + angle dial). TUX-044b deferred: the Layers list (hold-reorder at layers-panel.js, menu lane).

Help / README text:
- Drag a grip to reorder. On a touch screen, drag the grip. Hold near the top or bottom edge of the pane to scroll while you drag.
