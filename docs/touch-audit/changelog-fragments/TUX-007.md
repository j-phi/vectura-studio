# TUX-007 fragment

## CHANGELOG bullet
- iPhone landscape keeps a usable canvas (TUX-007). The classifier adds a `phone-short` body class (coarse pointer, height under 500). In that class the tool rail is one 52 px row, the modifier bar is a two-column block on the right (clear of the bottom inset), the formula pane is a 48 px chip, and the status strip is an overlay. Both side panes start closed. The fit scale is clamped (`Vectura.VIEW.minScale`), so a collapsed container cannot give a negative scale or a negative handle radius.
