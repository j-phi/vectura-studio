## Additional gaps against the acceleration contract

1. **P1, critical guards absent from the always-run lane.** `test:feedback:run` executes lifecycle, router contracts and one browser spec. It does not run the named seed-zero, saved-document/export, file-preset/default-origin, mask/transform/undo, curved-versus-faceted, ribbon width/placement/pen-scale, or import-sanitization guards. Add a small, explicit roster of current-code tests for these failure mechanisms and prove each detects its known bad implementation (mutation or pre-fix source). Keep the feedback deadline evidence honest: if this cannot fit under 60s, report the miss and retain full gates; do not drop guards to claim the target.
2. **P1 promotion blocker, Scene3D impacted audit routing is too narrow.** `src/core/scene3d/surface-fill.js` is unmatched and gets the unknown broad fallback, but an ordinary `src/core/algorithms/scene3d.js` change matches `core-algorithms` and omits `audit`. The moved mkTick/tone-law exhaustive proofs depend on both. Full coverage still runs them in shadow mode; a routed gate would omit them. Add an explicit Scene3D rule and route those source, tone-law, renderer/fixture and relevant test changes to the preserved proofs. A broad fallback for unmatched paths cannot compensate for a matched under-routed path. Verify rename/deletion/absent-base cases too.
3. **P2, audit memory optimization is incomplete.** The sequential mkTick loop still retains `pp` fill paths and `raster` for many mutant/cell combinations in `R`; only some results are scalar summaries. Preserve only records later assertions actually consume and release bulky paths/rasters promptly. Measure peak RSS before claiming the memory objective. Do not change fixture bars without a pre-fix sensitivity proof.
4. **P1, proof of moved test sensitivity remains necessary.** The routine dispatch test checks mkTick against ladder, while full 46-law distinction and an executable module-default mutant moved to audit. The tone-collapse routine asserts mappings but its saved-document byte-equivalence and rendered alias/caveat behavior moved to audit. The thin-width guard includes a faceted nonempty assertion but the richer mutant/contact proof moved to audit. Run the preserved audit once repaired, show at least the known dispatch, alias/migration, mkTick spacing/crumb/rim and tone-inversion defects still fail their intended guard, and record the result. Visual tone golden caching correctly regenerates fresh output for the flipped-ladder sensitivity test; verify that remains true under coverage.
5. **P2, cache coverage attribution is unproven.** The loader disables compilation cache only when coverage flags appear in `process.argv`/environment. Confirm the queued coverage invocation reaches that branch or compare source attribution with caching disabled; add a focused contract if detection is unreliable. Current full coverage thresholds must remain 74/76/74/62.
