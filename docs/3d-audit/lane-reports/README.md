# Lane reports (2026-09-05 session, orchestrator context-protection protocol)

Every implementer / reviewer / judge writes its FULL report here as
`<W-id>-<role>.md` (role = impl | review | judge | impl2 …) and returns to the
orchestrator ONLY the one-line pointer `REPORT docs/3d-audit/lane-reports/<file>`.
The lane secretary agent reads the files, keeps `LEDGER.md` current, and hands the
orchestrator ONE status line per unit. Untracked until wrap-up; decide then whether to commit.
