Object 3D Fill Style Review

A multi-agent audit of the 8 fill Types and 49 Fill Styles, run in three lenses: styles that can merge behind a parameter, performance, and artistic controls. Agents looped until each lens was saturated: a round of fresh, adversarial auditors found nothing new that mattered.

Summary

What the audit found

PerformanceRotation is slow because of 2 bugsDrag frames never use the draft render, and every edit renders twice. A prototype fix brought drag frames from 1–3.6 s down to 30–55 ms.
Merges4 style families + 9 sub-setting mergesMost of the identical-output pairs were confirmed by hashing output. No proposed merge breaks a preset.
ArtisticReach matters more than new knobs107 setting/surface combinations work in the engine but have no control. 48 combinations have a control that does nothing in some or all contexts.

Recommended first step: forward the draft flag to scene groups (B1) with a draft that keeps the Fill Style (F5), and fix the double render (B2). This gives the biggest win for the least work.

(b) Performance

  • "Closest approach" lives under three keys: fieldFloor, bundle step and wave cFlo.

Defects found while classifying

  • Any fieldMetric option silently drops the sigmoid curve.
  • rungMode:'perceptual' brings back the irregular-gap ladder that W-26 fixed.
  • On the 9 mono styles, Contour draws the same as Hatch.

Open

Decisions for Jay

  1. Shadow textures.The shadow Fill Style picker offers only merged styles, with no sub-controls. 17 shadow textures from earlier merges can no longer be picked, and each new merge removes 1–2 more. Should merges keep every look reachable?
  2. Seed.Seed is shown but never read. New layers get a random seed, so wiring it directly changes how every saved scene looks. Hide it now, or wire it behind a flag set only on new layers?
  3. Ribbon fix output change.The distance-field ribbon fix is 2.5–3× faster but changes output slightly, so the golden images need a refresh. Accept that?

Method: round 1 ran four lenses in parallel (merges, performance from code, performance measured live, artistic controls).
